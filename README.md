# 🌿 Plant World - 植物世界

## 📌 Project Description

A plant information website that allows users to view, add, and delete plants. The website supports full CRUD operations with data stored in MongoDB.

---

## 🛠️ Technologies Used

| Category | Technologies |
|----------|--------------|
| Frontend | HTML5, CSS3, JavaScript (ES6+) |
| Styling | Flexbox, CSS Grid, Media Queries |
| Backend | Node.js, Express.js |
| Database | MongoDB, Mongoose ODM |
| Version Control | Git, GitHub |

---
